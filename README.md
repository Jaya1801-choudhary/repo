# Multimodal Construction Intelligence Platform

This is a full-stack AI platform designed to assist construction professionals. It leverages a FastAPI backend and a React.js frontend to provide AI-driven insights.

## Features
1. **Safety & Crack Detection:** Analyzes construction site images for safety hazards and structural issues.
2. **AI Project Planning:** Generates project duration, market trends, and base valuation using AI.

## Tech Stack
* **Backend:** Python, FastAPI, SQLite
* **Frontend:** React.js, Vite, Axios
* **AI Integration:** Google Gemini AI
